# DRILL 09 — 소년 상하좌우 이동 및 방향 바꾸기

Python + pico2d로 방향키 이동, IDLE 애니메이션, 좌우 방향 전환 및 화면 경계 제한을 구현한 과제입니다.

## 직접 실행하기

Windows에서 이 폴더의 **`run.cmd`를 더블클릭**하세요. 현재 컴퓨터에는 과제 전용 `.venv`와 pico2d 설치가 준비되어 있습니다.

게임 창을 클릭한 뒤 방향키로 조작합니다.

| 입력 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 및 바라보는 방향 변경 |
| ↑ / ↓ | 마지막 좌우 방향을 유지하며 상하 이동 |
| 방향키 놓기 | 마지막 방향의 IDLE 애니메이션 |
| 수평 + 수직 방향키 | 대각선 이동, 직선과 같은 속도 |
| 반대 방향키 함께 누르기 | 해당 축 이동 상쇄; 한 키를 놓으면 남은 키로 이동 |
| 다른 창으로 전환 | 입력 초기화 및 정지 |
| Esc / 창 닫기 | 종료 |

800×600 화면 중앙에서 시작합니다. 이동 속도는 초당 200픽셀, 애니메이션은 10 FPS입니다. 100×100 캐릭터 셀 전체가 화면 안에 있도록 중심 좌표를 x=50~750, y=50~550으로 제한합니다. 경계에서 이동 키를 누르고 있으면 MOVE, 키를 놓으면 IDLE입니다.

## 다른 컴퓨터에서 설치

Python 3.10 이상을 설치한 뒤 저장소 폴더의 터미널에서 실행하세요.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe drill09.py
```

이미지는 소스 파일 위치를 기준으로 읽으므로 다른 작업 폴더에서 실행해도 됩니다. `.venv`는 Git에 포함되지 않으며 컴퓨터마다 설치해야 합니다.

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

실제 pico2d/SDL 창에서도 지정 이미지 로딩, 32개 프레임 렌더링, 방향키·포커스·Esc·종료 이벤트 전달을 검증했습니다. 다른 작업 폴더에서 리소스 로딩도 확인했습니다.

직접 실행 후 아래 항목을 확인하세요.

1. 시작 시 오른쪽 IDLE이 움직이는지 확인합니다.
2. ← / →로 방향이 바뀌고, ↑ / ↓에서는 그 방향이 유지되는지 확인합니다.
3. 키를 놓으면 정지하고 IDLE이 재생되는지 확인합니다.
4. 네 변과 모서리에서 화면 밖으로 나가지 않는지 확인합니다.
5. 두 키를 누른 상태에서 하나를 놓았을 때 나머지 입력이 유지되는지 확인합니다.
6. 다른 창으로 전환 후 돌아왔을 때 자동 이동하지 않는지 확인합니다.
